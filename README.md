# MPR 计划验证 1.0

MPR 计划验证是一款用于 CT 数据观察、三维空间确认、DRR 模拟 X 光验证和器械规划的桌面工具。软件面向术前规划、影像验证、教学演示和功能验证场景，帮助使用者在同一界面中查看 MPR 切片、3D 视图、AP/LAT DRR 图像，并规划导针或椎弓根螺钉的位置。

本软件生成的是基于 CT 数据的模拟 DRR 图像，不是真实 X 光采集结果，也不直接连接 C-arm、导航设备或真实器械库。

## 主要功能

- 导入本地 CT DICOM 文件夹，构建可浏览的体数据。
- 同时显示轴位、矢状位、冠状位 MPR 视图。
- 在 3D 视图中查看体数据、器械和空间关系。
- 实时生成 AP 与 LAT 两个方向的 DRR 模拟 X 光图像。
- 创建和编辑导针、椎弓根螺钉等规划器械。
- 在 MPR、3D、DRR 视图中同步显示器械位置和投影。
- 支持距离、角度和标签测量。
- 支持保存 `.mprproj` 规划工程。

## 界面区域

软件启动后，主界面由几类视图和控制面板组成：

- MPR 视图：轴位、矢状位、冠状位三个切片窗口，用于观察 CT 解剖结构和十字线位置。
- 3D 视图：显示体数据和已创建器械，用于确认器械在患者空间中的整体方向。
- DRR 视图：显示 AP X 光和 LAT X 光，用于观察器械在模拟 X 光中的投影。
- 右侧控制区：包含 DICOM 加载、患者体位、测量、器械规划、DRR 放置和 DRR 参数。

## 基本使用流程

1. 点击“加载 DICOM”，选择包含 CT DICOM 的文件夹。
2. 在三个 MPR 视图中移动十字线，确认目标解剖位置。
3. 通过滚轮、平移、缩放等操作浏览切片和 3D 场景。
4. 在“规划器械”中设置名称、长度和直径。
5. 使用“在十字线处添加导针”或“在十字线处添加螺钉”创建器械。
6. 在 MPR、3D、AP DRR 和 LAT DRR 中检查器械位置。
7. 需要从模拟 X 光中放置器械时，使用“DRR 导针”或“DRR 螺钉”，先在 AP 中绘制，再在受限 LAT 中微调。
8. 调整 DRR 参数，使模拟 X 光更适合观察骨结构和器械投影。
9. 点击“保存 .mprproj”保存当前规划。

## MPR 视图

MPR 视图用于在 CT 体数据中定位和观察目标结构。三个视图共享同一个患者坐标和十字线位置，任一视图中调整十字线，其他视图会同步更新。

使用建议：

- 先在轴位中确认目标椎弓根或骨性通道。
- 再结合矢状位和冠状位判断进针方向、深度和上下位置。
- 若需要非正交观察，可使用“自由斜切”模式调整切面角度。
- 测量距离或角度时，控件只会在完整测量所在位置显示，离开该位置时隐藏，避免误读。

## 3D 视图

3D 视图用于从整体空间关系上检查规划结果。创建导针或螺钉后，器械会同步显示在 3D 场景中。

使用建议：

- 用 3D 视图确认器械整体方向是否合理。
- 观察器械入口点、末端方向和骨结构之间的关系。
- 与 MPR 切片配合使用，避免只依赖单一视角判断。
- 当多个器械同时存在时，可通过器械列表选择、编辑或删除目标器械。

## DRR 模拟 X 光

DRR 视图使用 CT 体数据生成 AP 和 LAT 两个方向的模拟 X 光图像。器械会以投影形式叠加到 DRR 上，便于比较 MPR/3D 规划与 X 光表现之间的关系。

常用参数：

- SID/SOD：控制 X 光源、患者和探测器之间的几何距离。
- 探测器宽度/高度：控制输出图像尺寸。
- 像素间距：控制探测器像素对应的物理尺寸。
- 射线步长：影响 DRR 采样精度和速度。
- 窗位/窗宽/伽马：调整显示对比度。
- HU 偏移/HU 缩放：调整 CT 值参与 DRR 显示的映射，1.0 版本默认 HU 偏移为 -150，HU 缩放为 8。

使用建议：

- 先查看 AP，再查看 LAT，避免单一投影下的深度误判。
- 调整 HU 偏移和 HU 缩放时，关注骨皮质、椎弓根边界和器械投影是否清晰。
- 若 DRR 状态显示 CPU 回退，说明当前环境未使用 CUDA 实时路径，但仍可生成参考图像。

## 器械规划

软件当前支持两类参数化器械：

- 导针：适合用于路径确认和基础进针方向验证。
- 椎弓根螺钉：适合用于规划螺钉长度、直径和空间方向。

器械由入口点、方向、长度和直径定义。修改参数后，MPR、3D 和 DRR 视图会同步更新。

常用操作：

- 新建：在十字线位置添加导针或螺钉。
- 编辑：选择已有器械后进入编辑，调整长度、直径或位置。
- 删除：移除当前选中的器械。
- DRR 放置：在 AP 和 LAT 模拟 X 光中联合绘制，重建器械的三维位置。

## 数据与工程

- DICOM 数据以文件夹方式导入。
- 规划结果可保存为 `.mprproj` 工程文件。
- 工程文件保存规划参数和数据引用信息，不等同于复制完整 DICOM 数据。

## 使用提示

- 建议先确认患者体位，再进行器械规划和 DRR 验证。
- 对关键器械位置，应同时查看 MPR、3D、AP DRR 和 LAT DRR。
- DRR 是模拟图像，适合用于规划验证和教学演示，不应单独作为临床结论依据。
