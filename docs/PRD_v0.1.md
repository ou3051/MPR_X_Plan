# 骨科手术规划仿真软件 PRD v0.1

文档状态：草案
版本：v0.1
日期：2026-05-03
产品方向：Qt + VTK 桌面端椎弓根螺钉/导针规划与实时 X 射线仿真

## 1. 背景与目标

本产品面向骨科术前规划、术中影像预演和教学仿真场景，基于 CT DICOM 数据构建 MPR 视图与三维空间环境，支持用户手动放置参数化椎弓根螺钉或导针，并通过实时 X 射线仿真生成模拟 X 光片，用于验证器械位置、方向、长度和入路。

产品从第一版开始按照审批级医疗软件的工程要求构建，包括需求追踪、风险管理、单元测试、功能测试、算法验证测试、版本管理和变更控制。

## 2. 产品定位

### 2.1 产品定义

基于单序列 CT DICOM 的椎弓根螺钉/导针规划与 X 射线仿真桌面软件。

用户导入 CT DICOM 后，在 Axial、Sagittal、Coronal MPR 视图和 3D 视图中观察骨性结构，手动放置由直径和长度定义的导针或椎弓根螺钉，并通过实时 DRR 生成模拟 X 光片。

### 2.2 第一阶段临床场景

第一阶段聚焦椎弓根螺钉规划场景。

典型任务包括：

- 观察椎体及椎弓根解剖结构。
- 在 MPR 视图中选择螺钉或导针入点。
- 定义器械方向、长度和直径。
- 在 3D 视图中查看器械与骨结构的空间关系。
- 通过 AP、LAT 或自定义角度模拟 X 光片验证器械投影位置。

### 2.3 目标用户

- 骨科医生：进行术前规划和器械路径评估。
- 医学工程师：辅助医生完成规划、验证和术前沟通。
- 教学培训人员：用于模拟训练和影像教学。
- 测试与质量人员：执行医疗软件验证、确认和回归测试。

## 3. 范围定义

### 3.1 v0.1 范围内

- 仅支持 CT DICOM 文件夹导入。
- 不区分多序列，不做序列选择和融合。
- 不建立患者病历系统。
- 支持三正交 MPR 视图。
- 支持基础 3D 体数据或骨表面显示。
- 支持手动创建导针。
- 支持手动创建椎弓根螺钉。
- 导针和螺钉均为自绘制参数化几何体。
- 器械由入点、方向、长度、直径定义。
- 支持实时 X 射线仿真预览。
- 支持 AP、LAT 和自定义 X 射线视角。
- 支持保存规划工程文件。
- 支持导出模拟 X 光图像和基础截图。
- 建立单元测试、功能测试和算法验证测试框架。

### 3.2 v0.1 范围外

- 不做自动分割。
- 不做自动螺钉路径推荐。
- 不做真实 X 光与模拟 X 光配准。
- 不做术中导航。
- 不连接真实 C-arm、机械臂或外部硬件。
- 不做患者病历管理、预约、账号权限等 HIS/PACS 工作流。
- 不做厂商真实器械库。
- 不做多模态影像融合。
- 不做云端协作。

### 3.3 未来预留

- 真实 X 光与 DRR 配准。
- C-arm 姿态估计。
- 自动椎体识别与椎弓根路径建议。
- 分割模型导入。
- 厂商器械库。
- 手术导航系统对接。
- 审批资料自动化生成辅助。

## 4. 核心用户流程

### 4.1 新建规划

1. 用户打开软件。
2. 用户选择导入 DICOM 文件夹。
3. 软件读取 DICOM 文件并构建 CT 体数据。
4. 软件显示 Axial、Sagittal、Coronal MPR 视图。
5. 软件显示 3D 视图。
6. 用户调整窗宽窗位、缩放和平移。
7. 用户进入器械规划模式。

### 4.2 放置导针

1. 用户选择“导针”工具。
2. 用户在 MPR 或 3D 视图中定义入点。
3. 用户定义目标点或方向。
4. 软件生成参数化圆柱导针。
5. 用户设置导针直径和长度。
6. 软件在 MPR、3D 和 X 射线视图中同步显示导针。

### 4.3 放置椎弓根螺钉

1. 用户选择“椎弓根螺钉”工具。
2. 用户定义螺钉入点和方向。
3. 用户输入或调整螺钉直径。
4. 用户输入或调整螺钉长度。
5. 软件生成简化参数化螺钉模型。
6. 软件显示螺钉中心线、外径轮廓和端点。
7. 用户在 MPR 和 3D 视图中验证空间位置。

### 4.4 生成实时 X 射线仿真

1. 用户打开 X 射线仿真视图。
2. 用户选择 AP、LAT 或自定义角度。
3. 软件根据 CT 体数据生成实时 DRR。
4. 软件将导针或螺钉投影叠加到 DRR 上。
5. 用户调整 X 射线角度时，DRR 实时刷新。
6. 用户调整器械位置时，器械投影实时刷新。

### 4.5 保存与导出

1. 用户保存规划工程。
2. 软件保存 DICOM 引用信息、器械参数、X 射线视角和视图状态。
3. 用户导出模拟 X 光图像。
4. 用户导出 MPR 或 3D 截图。

## 7. 数据与坐标约定

### 7.1 坐标系统

软件内部应将医学空间数据统一管理在 DICOM 患者坐标系中，单位为毫米。

主要坐标包括：

- Image index coordinate：体素索引坐标。
- Image physical coordinate：图像物理坐标。
- DICOM patient coordinate：患者坐标。
- VTK world coordinate：渲染世界坐标。
- Qt screen coordinate：界面像素坐标。
- Detector coordinate：X 射线探测器平面坐标。

业务模型不得直接依赖 Qt screen coordinate 或 vtkActor transform。

### 7.2 器械模型

导针：

- type: guide_pin
- entryPointPatient
- directionPatient
- lengthMm
- diameterMm

椎弓根螺钉：

- type: pedicle_screw
- entryPointPatient
- directionPatient
- lengthMm
- diameterMm
- simplifiedThreadVisible
- headVisible

v0.1 中螺钉可采用简化参数化模型，不要求真实螺纹几何精度。

### 7.3 X 射线视角模型

X 射线视角应包含：

- sourcePositionPatient
- detectorCenterPatient
- detectorU
- detectorV
- sid
- sod
- detectorPixelSpacing
- detectorResolution
- presetName

## 9. 风险与控制

| ID | 风险 | 可能后果 | 初步控制措施 |
| --- | --- | --- | --- |
| RISK-001 | DICOM 坐标解析错误 | 器械位置显示错误 | 坐标单元测试、phantom 验证、导入检查 |

| RISK-004 | DRR 投影几何错误 | 模拟 X 光误导用户 | CPU 参考实现、解析 phantom 验证 |
| RISK-005 | 模拟 X 光与真实 X 光混淆 | 用户错误使用结果 | 明确 UI 标识、导出文件命名和导出元数据；DRR 图像像素默认不叠加水印 |
| RISK-006 | 数据异常导致崩溃 | 软件不可用或数据丢失 | 异常处理、负面测试、保存保护 |
| RISK-007 | GPU 与 CPU DRR 不一致 | 实时预览失真 | GPU/CPU 差异测试和误差阈值 |
